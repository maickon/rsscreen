Política de privacidade

O rsscreen coleta o mínimo de dados possível. Aqui está, em linguagem simples, o que é guardado, por quê e como você pode pedir para ver ou apagar seus dados, conforme a Lei Geral de Proteção de Dados (LGPD).

Última atualização: 14/11/2026

Resumo

  • Não usamos cookies de rastreamento nem ferramentas de propaganda no site.
  • As ferramentas grátis (calculadora, proposta, tabela de preços) fazem as contas no seu aparelho. O que você digita fica só no seu navegador e não é enviado para nós.
  • Dos clientes, guardamos só o necessário para prestar o serviço e cobrar.
  • Das telas, guardamos dados técnicos de funcionamento por até 35 dias.

1. Quem cuida dos dados

O controlador dos dados é o rsscreen. Para qualquer pedido sobre seus dados, fale pelo WhatsApp.

2. Dados de clientes (quem assina as telas)

DadoPara quê
Nome do estabelecimento ou da pessoaIdentificar o cliente e gerar os links das telas.
WhatsAppEnviar os links, avisos e cobranças.
Plano, valor, quantidade de telas e vencimentoControlar a assinatura e a cobrança.
Anúncios (textos, preços, imagens) e playlistsMostrar o conteúdo contratado nas telas.

Base legal: execução do contrato e cumprimento de obrigações legais (como as fiscais). Esses dados ficam no banco de dados do sistema, acessível só pelo administrador com senha.

3. Dados técnicos das telas e do site

Para saber se as telas estão funcionando e evitar abusos, o sistema registra:

  • qual link de tela foi aberto (cliente, conteúdo e modelo);
  • um código aleatório do aparelho, criado pela própria tela (não identifica a pessoa);
  • o endereço IP e o tipo de navegador ou player;
  • contagens de acesso por dia e erros de carregamento das fontes de notícias.

Esses registros são apagados automaticamente depois de 35 dias. Base legal: legítimo interesse em manter o serviço funcionando e seguro.

4. Dados guardados só no seu aparelho

O site e as telas usam o armazenamento do navegador (localStorage) para funcionar melhor: os campos das ferramentas grátis, a última versão do conteúdo (para a tela continuar sem internet) e, no painel do administrador, a lista de links salvos. Esses dados não são enviados para nós e podem ser apagados limpando os dados do navegador.

5. Serviços de terceiros

Para funcionar, o rsscreen usa estes serviços, que podem receber o endereço IP de quem acessa:

  • Cloudflare: hospedagem do site, do sistema e do banco de dados.
  • Google Fonts: fontes das letras do site e das telas.
  • Sites de notícias: as imagens das notícias são carregadas dos próprios sites.
  • Open-Meteo (clima), AwesomeAPI (cotações), ESPN (futebol), CAIXA e apiloterias (loterias): fontes dos dados mostrados nas telas.
  • AllOrigins: serviço público usado só como reserva, se o leitor de notícias do próprio sistema falhar.
  • WhatsApp: quando você clica em um botão de contato.

Não vendemos nem alugamos dados pessoais para ninguém.

6. Por quanto tempo guardamos

  • Dados técnicos das telas: 35 dias.
  • Dados de clientes: enquanto a assinatura estiver ativa e, depois, pelo prazo exigido por lei (por exemplo, obrigações fiscais).
  • Anúncios: até serem excluídos no painel. Imagens que não são mais usadas são apagadas automaticamente.

7. Seus direitos (LGPD)

Você pode pedir a qualquer momento: confirmação de que tratamos seus dados, acesso a eles, correção, exclusão, informação sobre com quem são compartilhados e revogação de consentimento. Basta pedir pelo WhatsApp. Respondemos em até 15 dias. Você também pode procurar a Autoridade Nacional de Proteção de Dados (ANPD).

8. Segurança

O acesso ao painel exige senha, a comunicação é feita com HTTPS e os dados ficam na infraestrutura da Cloudflare. Nenhum sistema é 100% seguro, mas adotamos as medidas razoáveis para proteger as informações e avisaremos os afetados em caso de incidente relevante.

9. Mudanças nesta política

Esta política pode ser atualizada. A data da última atualização fica no topo da página.
